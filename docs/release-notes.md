# DaliScope 0.1.0

This release prepares DaliScope for installation and use outside the original laboratory environment.

- Consolidated package metadata and direct dependencies; Python 3.10 or newer.
- Added a short quickstart, English usage/data-format/preparation guides, and example provenance checksums.
- Made the data-pack generator configurable, with explicit database paths and opt-in uploads.
- Added regression tests and fresh-kernel notebook checks.
- Separated the larger GOLD pack into an optional release asset.

See `docs/validation.md` for tested behavior and remaining browser/production-database checks. Original DALI scores remain unchanged by domain clipping; case-study interpretations must be assessed against their frozen inputs and parameters.
